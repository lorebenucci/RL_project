## 📌 Abstract
The integration of Deep Learning into computational chemistry has revolutionized drug discovery and toxicology prediction. However, the lack of interpretability in these "black box" models remains a significant barrier to their adoption in critical healthcare applications. This work introduces a framework for Explainable AI designed to better understand toxicity predictions made by Deep Graph Networks (DGNs). Using the Tox21 dataset from MoleculeNet, we train a DGN to predict molecular toxicity across multiple biological targets. To generate explanations, we employ a Reinforcement Learning agent based on a Double Deep Q-Network (DDQN) architecture. This agent learns to generate molecular counterfactuals by applying discrete perturbations—such as adding or removing atoms and bonds—to the input molecular graph. By identifying the minimal structural changes required to flip the model's prediction from "toxic" to "non-toxic" (or vice versa), the framework isolates specific substructures responsible for the compound's toxicity.

## 📌 Overview
This project addresses the critical challenge of interpretability in Artificial Intelligence applied to Computational Chemistry. Deep Learning models often function as "black boxes." Our work proposes a **Counterfactual Explanation** framework designed to uncover *why* a specific molecule is classified as toxic.

The approach is divided into three main stages: Data Analysis, Predictive Modeling, and Counterfactual Generation via Reinforcement Learning.

### 1. 📖 Data Exploration and Preparation
The project utilizes the **Tox21** dataset from *MoleculeNet*, a standard benchmark for molecular machine learning. The dataset contains qualitative toxicity measurements for compounds across 12 different biological targets (e.g., nuclear receptors and stress response pathways).
* **EDA (Exploratory Data Analysis):** We conducted a thorough analysis to handle class imbalances and missing values, ensuring a robust training set.
* **Representation:** Molecules are processed not as fixed vectors, but as **molecular graphs**, where atoms represent nodes and chemical bonds represent edges.

### 2. 🕸️ The Predictor: Deep Graph Network (DGN)
To predict toxicity, we implemented a **Deep Graph Network (DGN)**. This model serves as the "Oracle" or the system to be explained.
* **Architecture:** The DGN is a multi-task learning model capable of handling the graph structure of molecules directly.
* **Function:** It maps the input molecular graph to a toxicity prediction vector. This model was trained and optimized (hyperparameter tuning) to achieve high predictive accuracy on the Tox21 tasks.

### 3. 🤖 The Explainer: Reinforcement Learning Agent
The core contribution of this work is the explanation module, which uses **Reinforcement Learning (RL)** to generate counterfactuals.
* **Methodology:** We treat the generation of explanations as a sequential decision-making process.
* **Agent:** We employ a **Double Deep Q-Network (DDQN)** agent.
* **Mechanism:** The agent iteratively modifies the input molecule by performing discrete actions (perturbations), such as adding or removing specific atoms and bonds.
* **Goal:** The agent's objective is to find the minimal set of structural changes required to **flip the DGN's prediction** (e.g., transforming a "Toxic" classification into "Non-Toxic").

### 4. Outcome: Interpretable Explanations
By comparing the original molecular graph with the counterfactual graph generated by the DDQN agent, we can isolate the specific structural differences.
* **Toxicophore Identification:** These differences highlight the exact substructures (toxicophores) responsible for the toxicity.
* **Decision Boundary:** This process illuminates the decision boundary of the DGN, providing chemists with actionable insights into which chemical features drive the model's predictions.
